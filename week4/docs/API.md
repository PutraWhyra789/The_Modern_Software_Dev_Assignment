## Notes

Endpoints for creating, reading, updating, searching, deleting, and extracting content from notes.

---

### GET /notes/

Return all notes in the database.

**Request**

| Parameter | In | Type | Required | Description |
|-----------|----|------|----------|-------------|
| _(none)_  | —  | —    | —        | —           |

**Response**

| Status | Body | Description |
|--------|------|-------------|
| `200 OK` | `NoteRead[]` | Array of all notes (may be empty) |

`NoteRead` schema:

```json
{
  "id": 1,
  "title": "string",
  "content": "string"
}
```

**Example**

```bash
curl http://localhost:8000/notes/
```

```json
[
  { "id": 1, "title": "Welcome", "content": "This is a starter note. TODO: explore the app!" },
  { "id": 2, "title": "Demo",    "content": "Click around and add a note. Ship feature!" }
]
```

### POST /notes/

Create a new note.

**Request body** (`application/json`)

| Field     | Type   | Required | Constraints         |
|-----------|--------|----------|---------------------|
| `title`   | string | ✅ yes   | 1–200 characters    |
| `content` | string | ✅ yes   | minimum 1 character |

**Response**

| Status | Body | Description |
|--------|------|-------------|
| `201 Created` | `NoteRead` | The newly created note |
| `422 Unprocessable Entity` | validation error | Missing field or constraint violated |

**Example**

```bash
curl -X POST http://localhost:8000/notes/ \
  -H "Content-Type: application/json" \
  -d '{"title": "Sprint planning", "content": "TODO: groom the backlog. #planning #backend"}'
```

```json
{ "id": 3, "title": "Sprint planning", "content": "TODO: groom the backlog. #planning #backend" }
```

### PUT /notes/{note_id}

Update a note's title and/or content. Only supplied fields are changed (partial update).

**Request**

| Parameter | In   | Type    | Required | Description    |
|-----------|------|---------|----------|----------------|
| `note_id` | path | integer | ✅ yes   | ID of the note |

**Request body** (`application/json`)

| Field     | Type   | Required | Constraints         |
|-----------|--------|----------|---------------------|
| `title`   | string | ❌ no    | 1–200 characters    |
| `content` | string | ❌ no    | minimum 1 character |

Sending an empty `{}` body is a valid no-op.

**Response**

| Status | Body | Description |
|--------|------|-------------|
| `200 OK` | `NoteRead` | The updated note |
| `404 Not Found` | `{"detail": "Note not found"}` | No note with that ID |
| `422 Unprocessable Entity` | validation error | Empty string passed for a constrained field |

**Example**

```bash
curl -X PUT http://localhost:8000/notes/1 \
  -H "Content-Type: application/json" \
  -d '{"title": "Updated welcome"}'
```

```json
{ "id": 1, "title": "Updated welcome", "content": "This is a starter note. TODO: explore the app!" }
```

### POST /notes/{note_id}/extract

Parse a note's content and extract:

- **Action items** — lines ending with `!` or starting with `todo:` (case-insensitive)
- **Tags** — `#hashtag` patterns (deduplicated, lowercased, sorted alphabetically)

Optionally persist the extracted action items as new `ActionItem` rows.

**Request**

| Parameter    | In    | Type    | Required | Description                                                          |
|--------------|-------|---------|----------|----------------------------------------------------------------------|
| `note_id`    | path  | integer | ✅ yes   | ID of the note to extract from                                       |
| `save_items` | query | boolean | ❌ no    | If `true`, save extracted action items to the DB (default: `false`)  |

**Response**

| Status | Body | Description |
|--------|------|-------------|
| `201 Created` | `ExtractResult` | Extracted action items and tags |
| `404 Not Found` | `{"detail": "Note not found"}` | No note with that ID |

`ExtractResult` schema:

```json
{
  "action_items": ["string"],
  "tags": ["string"]
}
```

**Example — extract only (dry run)**

```bash
curl -X POST "http://localhost:8000/notes/2/extract"
```

```json
{
  "action_items": ["Ship feature!"],
  "tags": []
}
```

**Example — extract and save action items**

```bash
curl -X POST "http://localhost:8000/notes/2/extract?save_items=true"
```

```json
{
  "action_items": ["Ship feature!"],
  "tags": []
}
```

> `"Ship feature!"` is now saved as a new `ActionItem` row with `completed = false`.

### POST /action-items/

Create a new action item.

**Request body** (`application/json`)

| Field         | Type   | Required | Constraints         |
|---------------|--------|----------|---------------------|
| `description` | string | ✅ yes   | minimum 1 character |

New items are always created with `completed = false`.

**Response**

| Status | Body | Description |
|--------|------|-------------|
| `201 Created` | `ActionItemRead` | The newly created item |
| `422 Unprocessable Entity` | validation error | Missing or empty description |

**Example**

```bash
curl -X POST http://localhost:8000/action-items/ \
  -H "Content-Type: application/json" \
  -d '{"description": "Review PR #42"}'
```

```json
{ "id": 3, "description": "Review PR #42", "completed": false }
```

### PUT /action-items/{item_id}/complete

**Request**

| Parameter | In   | Type    | Required | Description           |

**Response**

| Status | Body | Description |
|--------|------|-------------|
| `200 OK` | `ActionItemRead` | The updated item with `completed: true` |
| `404 Not Found` | `{"detail": "Action item not found"}` | No item with that ID |

